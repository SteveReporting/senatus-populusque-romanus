# Imperial Editorial Redesign

## Goal
Transform the Roman Mainframe into the selected black, gold, and red imperial magazine direction without changing its live Trello data, routes, social links, or judicial integration.

## Build
- Rework the shared header and footer into a restrained gazette masthead with clear archive navigation and search.
- Recompose the homepage as an asymmetric editorial grid featuring the SJC crest, live system totals, archive entry points, legal excerpts, and judicial access.
- Replace the existing navy-heavy styling with semantic black, parchment-gold, and Roman-red tokens while retaining readable dark surfaces.
- Keep Cormorant Garamond for classical headings and move body copy to Karla.
- Adapt shared section headings and rotating quotations to the new visual hierarchy.
- Preserve mobile usability, reduced-motion behavior, and all existing destinations.

## Technical details
- Changes remain frontend-only and use the existing React, Tailwind, and semantic token system.
- Existing Trello hooks and data parsing remain unchanged.
- Verify the homepage at desktop and mobile sizes, plus current build and runtime signals.
